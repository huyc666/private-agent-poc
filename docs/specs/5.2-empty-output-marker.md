## 1. 背景与目标

`server/orchestration.py` 的 `_step_messages` 处理步骤 `inputs` 时，对
`outputs.get(ref)` 取不到内容就整段跳过，不报错、不记日志、不留标记；下游
模型无法区分「上游没产出」与「没引用上游」，实例状态仍为 completed。
`_parse_fanout` 在上游产出为空时兜底成 `[task]`，同样静默。

目标：空产出或缺失时向下游 prompt 写入显式标记「上游步骤 X 输出为空」；
并行扇出来源为空而退回总任务时，子任务 prompt 同样给出可见标记。不失败、
不修改 `ok` / `failed_step` / 实例终态判定，不改变串行、并行、aggregate
既有行为。本任务独立于 4.3，单独提交、单独版本记录。
