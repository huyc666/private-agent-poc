# Spec — 2.2 检索问答与出处标注（结构化出处卡片 + 分层排版定位 + 多库并联 + 防编造）

## 1. 背景与目标

PLAN.md 2.2（优先级 8，规模 L→XL 边缘，依赖 2.1 ✅ v0.17.24）。现状：混合检索
已交付，出处为「【来源：文档名 · 章节标题】」纯文本，只能人工翻原文核对。本项补齐：

1. **结构化出处卡片**：检索结果以独立 SSE 事件直推前端渲染出处卡片，
   数据绕过模型转写，链接参数 100% 可信；
2. **分层排版定位**：点击出处按格式分流——pdf 原生查看器跳页（真实排版）、
   docx mammoth 还原语义排版并高亮命中段落、其余格式文本片段页高亮；
3. **多库并联**：提示词引导模型分别调用各库工具后综合作答、出处合并；
4. **防编造**：无命中明确说明，出处/锚点数据不经过模型。

做完的样子：提问 → 模型干净作答 → 消息下方出处卡片（可折叠、整行可点）→
点击按格式打开对应视图并定位/高亮命中处；历史会话回放卡片仍在。

## 2. 需求分析与约束条件澄清

### 功能边界
- **做**：① 锚点——kb_parsers 产出「伪 markdown + 行→锚点映射」，chunks 表加
  `anchor` 列（md/txt=行区间 line、pdf=页码 page、docx=段落序号 para、
  pptx=页 slide、xlsx=Sheet+行 sheet）；② 工具输出尾部附加
  `<kb-citations>{json}</kb-citations>` 机器可读块；③ 服务端 on_tool_end 解析
  该块 → 新 SSE 事件 `citations` 推前端，给人看的工具文本剥离该块；
  ④ 前端出处卡片（折叠/整行可点/多工具合并去重/历史回放）；
  ⑤ 定位端点 GET /api/kb/source 按 kind 分流：page(pdf)→原始 pdf 流（前端
  `<a>` 附 `#page=N` 原生跳页）、para(docx)→mammoth 渲染页（vendor 本地化，
  mammoth 失败降级文本片段页）、line/sheet/slide→文本片段页（±5 行上下文+
  高亮命中区）；⑥ pack.yaml 新增可选 `knowledge_bases: [库名]` 声明，
  定位端点按「kb 名 ∈ 启用包声明集合且该包 allowed_roles 放行当前角色」校验；
  ⑦ 平台系统提示词：多库协作规则 + 防编造约束。
- **不做**：聚合检索工具（归 2.3 与库注册表一起）；部门维度控库（2.3）；
  pdf 行级高亮（需 pdf.js，POC 不做）；pptx/xlsx 排版还原（文本片段页）；
  扫描件定位（无文本层本就跳过）；OCR。

### 约束（受既有约定影响）
- **fail-closed**：未登录 401；kb 名未声明/包 RBAC 拒绝/文档名非法 → 404；
  开放模式（AUTH_ENABLED=false）放行与现有一致。
- **逻辑路径红线**：卡片链接与页面只出现 `kb/<库名>/<文档名>` 逻辑路径；
  错误信息不回显 {e}、不含绝对路径。
- **路径穿越防御**：doc 参数禁 `/`、`\`、`..` 与控制字符（NFC 归一化后校验），
  kb 名限 `[a-z0-9_-]+`；源文件路径服务端拼接，越界一律 404。
- **citations 数据不进模型正文**：给人看的工具文本剥离 `<kb-citations>` 块
  （模型仅见人读出处行）；SSE 侧截断（2000）在剥离之后进行，出处行完整。
- **无锚点降级**：anchor NULL 的块正常入库与检索，citations 对应条目无链接
  （显示「无锚点」不可点），不阻塞；锚点生成失败不阻塞索引。
- **历史回放**：citations 随 assistant 消息持久化（sessions 存储），重新打开
  会话卡片仍可渲染。
- **离线前端**：mammoth.js 必须 vendor 本地（web/vendor/，内网断网可用），
  不引 CDN。

### 待澄清问题（已全部答复，2026-10-17 用户确认）
1. **出处展示形态** → **B 结构化卡片**（citations SSE 事件 + 前端卡片组件，
   数据绕过模型）。
2. **点击定位视图** → **分层排版还原**：pdf 原生跳页 + docx mammoth 还原
   （段落高亮）+ 其余文本片段页；接受 docx 无页码、pdf 不行级高亮两个物理限制。
3. **多库并联** → **方案一提示词引导**（不加聚合工具；聚合归 2.3）。
4. **定位端点权限** → **登录 + 包 RBAC 跟随**（kb 名→包声明映射，allowed_roles
   放行才可读；堵住绕过工具层 RBAC 的遍历旁路；部门维度归 2.3）。

## 3. 关键技术与选型决策

| 决策点 | 候选 | 选定 | 理由 |
|---|---|---|---|
| 出处数据通路 | 模型转写链接 / 服务端 SSE 直推 | **服务端直推**：工具输出尾附 `<kb-citations>` 块，on_tool_end 解析→`citations` 事件→给人看文本剥离该块 | 链接参数不经模型，100% 可信；模型仍见人读出处行可自然引用 |
| 锚点存储 | 独立表 / chunks 加列 | **chunks 加 `anchor` TEXT 列**（JSON：kind/a/b/label） | 与块同生命周期；NULL 降级；查询一次取出 |
| 锚点生成 | 每格式各写 / 解析器统一映射 | **kb_parsers 返回 (伪md, 行→锚点列表)**，chunk 锚点=块内首末行锚点聚合 | 伪 md 行号即天然坐标；pdf 页/docx 段落由解析器标注 |
| chunk_markdown 兼容 | 改签名 / 新增变体 | **保留原签名，新增 `chunk_markdown_anchored`** | 2.1 测试与既有行为零回退 |
| docx 还原 | pdf.js 级全还原 / mammoth / 纯文本 | **mammoth.js vendor 本地**，失败降级文本片段页 | 语义排版够 POC；离线前端硬约束 |
| pdf 定位 | pdf.js 高亮 / 原生查看器跳页 | **原生查看器**：端点吐原始 pdf 流，`<a>` 附 `#page=N` | 零依赖；行级高亮成本不成比例 |
| kb→包映射 | 扫描工具源码 env / pack.yaml 声明 | **pack.yaml 可选 `knowledge_bases` 显式声明** | 显式、fail-closed（未声明即不可定位）、不解析源码 |
| 前端卡片 | 完整组件库 / 原生 JS | **原生 JS 单文件内联**（index.html 现有模式） | 不引前端框架；HTML 转义先行防注入 |
| 历史回放 | 重放 SSE / citations 入库 | **citations JSON 随 assistant 消息持久化**，回放直接渲染 | 重放不可靠且贵 |

## 4. 验收标准

| # | 验收标准 | 验证方式 |
|---|---|---|
| AC1 | 五类格式+md/txt 入库后 chunks.anchor 非空且 kind 正确（md/txt=line、pdf=page、docx=para、pptx=slide、xlsx=sheet）；md/txt 行号与源文件逐字对上 | 单测（程序化样例） |
| AC2 | 工具输出=人读片段（出处行在前）+ 尾部 `<kb-citations>` JSON 块，JSON 条目与出处行一一对应；剥离块后给人看文本 ≤2000 且出处行完整 | 单测 |
| AC3 | 服务端 on_tool_end 解析块→发 `citations` SSE 事件；SSE 工具文本不含 `<kb-citations>` | 单测（事件流层） |
| AC4 | 前端：citations 事件渲染出处卡片（折叠/整行链接 target=_blank）；多次工具调用合并去重；HTML 转义防注入；citations 随消息持久化、历史回放可渲染 | 前端纯函数静态断言（单测）+ 手工实测 |
| AC5 | 定位端点分流：kind=line/sheet/slide 返回文本片段页（±5 行上下文、命中区高亮、与源文件逐字一致）；kind=page 返回原始 pdf 流（Content-Type 正确）；kind=para 返回 mammoth 渲染页（vendor 本地引用，含降级路径） | 单测（端点级） |
| AC6 | 拒绝路径：未登录 401；kb 未在启用包声明集合 404；包 allowed_roles 拒绝当前角色 404；doc 含 `/`/`\`/`..`/控制字符 404；错误信息无绝对路径；开放模式放行 | 单测（安全） |
| AC7 | 无锚点块降级：anchor NULL → citations 条目无链接显示「无锚点」，索引与检索不报错 | 单测 |
| AC8 | 多库并联：系统提示词含多库协作规则；门控集成测（RUN_LLM_TESTS）实测两库合并作答出处并列 | 单测（文案断言）+ 门控实测 |
| AC9 | 防编造：系统提示词含「无命中如实说明、出处必须来自检索结果、不复述 kb-citations 标签」约束；工具无命中文案保留 | 单测（文案断言）+ 门控实测 |
| AC10 | pack.yaml `knowledge_bases` 声明生效：core-knowledge=[common]、kb-demo=[hr]；未声明库不可定位 | 单测 |
| AC11 | 包工具升级后自包含（不 import server/tools，AST 断言）；重签名后可信（部署侧 sign_pack） | 单测 + 手工 |
