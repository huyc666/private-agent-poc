# Human-Centered UI：PAP 核心页面审计与改造

日期：2026-11-21。环境：隔离的 mock 服务 `127.0.0.1:7107`、独立数据库与测试账号，未使用生产数据库。浏览器：本机 Microsoft Edge + Playwright，桌面 `1440×900`、窄屏 `390×844`。截图位于 `.screenshots/human-centered-ui/`；该目录与本地凭据均不入库。

## 方向

保留 Private Agent 的私密、可信、任务导向定位，以“克制的深青与暖白、内容优先、少装饰”为共同语言。不是把一切做成极简空白，而是让用户更快提问、理解回答、继续会话和完成管理任务。这一气质是设计判断，尚无用户研究支持。

约束：保持原生 HTML/CSS/JS、离线零 CDN、现有业务 ID、权限、API 与危险操作确认。无外部字体、图标或运行依赖。

## 审计证据

| 优先级 | 基线事实与位置 | 用户影响 | 处理 |
| --- | --- | --- | --- |
| 高 | `before-chat-mobile.png`：关闭的记录面板仍挤压内容；仅检查页面宽度未捕获 | 聊天被挤成窄条，发送区域不可正常使用 | 隐藏面板增加 `visibility`，桌面才预留侧栏空间；补元素边界断言 |
| 高 | `before-console-mobile.png`：标题、导航和表格同时争抢宽度 | 逐字换行，操作扫描困难 | 顶栏换行、导航保持词组，表格仅局部横向滚动 |
| 中 | `before-chat-desktop.png`、`before-console-users.png`：蓝紫渐变、emoji、胶囊和卡片竞争视觉焦点 | 通用模板感强，主任务与数据层级被装饰分散 | 深青纯色强调、统一文字层级、紧凑圆角、去装饰性 emoji |
| 中 | `web/index.html`、`web/console.html`：多个 `span` 只有鼠标点击 | 键盘用户无法可靠操作记录与页签 | 补角色、名称、Enter/Space、当前状态和焦点样式 |
| 中 | 控制台危险弹窗没有 Escape 与焦点约束 | 键盘可能跑到遮罩后，取消路径不清 | 补 dialog 语义、初始/循环/恢复焦点和 Escape |

值得保留：原有两页共享 token、管理员与用户权限差异、危险操作明确后果、聊天历史与审批入口、表格信息密度，以及离线零依赖架构。

## 改造结果

- `web/tokens.css`：统一暖白背景、深青强调、墨色文本、语义状态、焦点环、字体、圆角与 reduced-motion；原生与 `role=button` 按钮文字居中。
- `web/index.html`：欢迎区改为任务引导与示例；统一消息和输入宽度；改善顶栏、消息、记录面板、登录文案；补键盘和侧栏状态；上传/输入/发送初始高度统一为 48px，关闭按钮统一为 36px 图标按钮。
- `web/console.html`：清晰管理任务标题、轻量页签与表格；移动端顶栏/筛选布局；局部滚动；模态键盘行为。
- `tests/test_human_centered_ui.py`：无第三方解析依赖的静态契约测试；首版错误要求原生关闭按钮带 `tabindex`，已修正为检查其可访问名称。
