基线版本 v0.17.10。来源：对照 FEATURES.md 设计清单与当前实现的差距盘点

## 执行优先级

排序原则：快赢与解锁项先行 → 核心价值主线（RAG）尽早启动 → 管理能力跟上 →
编排与工作流 → 生态与部署收尾。

| 批次 | 序号 | 事项 | 批次目标 |
|---|---|---|---|
| 一（快赢与解锁） | 1-6 | 6.1 → 1.1 → 1.2 → 6.5 → 6.2 → 6.6 | 部门字段解锁下游；权限体系闭环；计量金额化与 run 健康度兑现 |
| 二（核心主线） | 7-10 | 2.1 → 2.2 → 2.3 → 2.4 | RAG 全链路交付：入库、检索问答、多库权限、一库多包共享 |
| 三（管理能力） | 11-13 | 3.1 → 6.3 → 3.2 | 控制台用户/Key 管理；审计落地；审批面板 |
| 四（编排与工作流） | 14-16 | 5.1 → 4.1 → 4.2 | 通用编排引擎；流程固化；定时/事件触发 |
| 五（生态与部署） | 17-24 | 4.3 → 6.7 → 6.4 → 7.3 → 7.1 → 7.2 → 7.4 → 6.8 | 文档生成流程；run 归因与跨机存储；包市场与集成生态；run 等待耗时 |
