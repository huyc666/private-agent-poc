# 天气简报生成

当用户要求生成某个城市的天气简报时，按以下步骤执行：

1. 调用天气工具（`get_current_weather` 或 `get_city_weather`）获取目标城市实时天气。
2. 按下面的格式输出简报：

```
【天气简报】<城市> · <日期>
天气：<天气状况>    气温：<气温>（体感 <体感温度>）
湿度：<湿度>    风速：<风速>
出行建议：<根据天气状况给一句话建议，例如带伞/注意防晒/适宜出行>
```

3. 出行建议规则：
   - 有雨/雪/雷暴 → 提醒携带雨具、注意防滑
   - 晴且风速小 → 适宜户外活动
   - 雾/霾 → 提醒注意交通安全
   - 其他 → 简短中性建议
