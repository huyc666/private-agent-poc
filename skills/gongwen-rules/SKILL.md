# 公文格式规则手册（决策层，2026-09-25 用户拍板）

本技能只沉淀**判定规则与决策口径**，不做 python-docx 实现；真正批量校正 docx 交给 `gongwen-format` 技能（其 `references/gongwen_autofix.py` 已实现下列全部规则）。本手册用于：在动手前先判断"该段落/该要素该怎么处理"，也便于在其他公文场景直接复用口径。

## 适用前提
待调整文档含「一、」「（一）」「一是」「（1）」「1.」「1.1」等层次序号标记的段落，或涉及页码、结语、结构要素（红头/主送/落款/日期）的取舍。

## 一、六则处理规则（全文通用）

1. **各级标题缩进与行距**：一~四级标题与正文一样**首行缩进 2 字**（≈Pt(32)=640 twips）、**行距固定 28 磅**（exact）；**二级标题楷体、不加粗**（三/四级仿宋，均不加粗）。
2. **保留原文标题**：未明确"改名/改为新标题"时，一律保留原大标题文字，不臆改文种（改名须显式 `--title`）。
3. **二级及以下标题融入正文**：标题未独立成段、接在正文同一段（如"（一）组织领导机制。单位印发…"）→ 与正文同字体（仿宋）；以第一个"。"为标题截止——**标题部分加粗，其后正文不加粗**。
4. **页码：修改不新增**：原文已有页码（PAGE 域或"— —"手动占位符）→ **改写**为标准格式（宋体四号、`— N —`、奇右偶左），**不重复新增**；原文无页码 → **不添加**（除非显式 `--add-page`）。
5. **文末结束语默认不保留**：默认不添加结语（如"以上报告，请审阅。"），并**移除原文末尾已有的结束语**；仅显式要求（`--add-jie` / `--jie`，或说"加结语/带结束语"）才补充。
6. **序号开头的段落均须判定标题（中文标记不再"恒为标题"）**：见下。

## 二、标题判定决策流程（核心，规则 6）

**判定顺序：先判"是不是标题"，再判"独立还是行内"。**

### 2.1 是不是标题？（`_is_cn_heading` / `_looks_like_heading` 的人类可读版）
对首字带序号的段落，依次检查：
- **长度门槛**：标题候选 = 序号之后到第一个"。"（含）或段末。候选 **> 30 字 → 判为正文**（标题是对本段的概括，不会太长）。
- **枚举列举**：本段内还出现**后续同级序号**（"二、" "（二）" "二是" "（2）"等）→ 整段是枚举，开头序号也归**正文**（"一"随之归正文）。
- **数字分支附加**：以年份开头（"2024年…"）、含句末"。"且残余文字过长 → 正文；短短语（"1. 加强组织领导"）→ 标题。
- 通过上面检查 → 视为**标题**（首句为本段概括、短小）。

> 反例速记：
> - "（一）关于进一步加强信息化项目建设与数据治理工作的若干意见。" → 标题候选 >30字 → **正文**
> - "（一）单位成立背景。二、单位发展历程。三、单位未来规划。" → 含后续序号 → **正文（枚举）**
> - "（一）组织领导机制。单位印发《通知》…" → 候选短、无后续序号 → **标题（行内）**

### 2.2 是标题后：独立还是行内？（`_maybe_inline`）
- 找到第一个"。"且其后仍有正文 → **行内标题**：标题部分加粗、其后正文不加粗，字体与正文一致。
- 否则 → **独立标题**：整段按层级设字体/缩进/行距。

### 2.3 层级映射
| 标记样式 | 层级 | 字体（不加粗） |
|---|---|---|
| 一、二、三、 | 一级 | 黑体 |
| （一）（二） | 二级 | 楷体 |
| 一是、二是 / 1. / 1、 / 1.1 | 三级 | 仿宋 |
| （1）（2） | 四级 | 仿宋 |

## 三、结构要素 opt-in 原则
红头文件、主送机关、落款、日期**仅当用户明确提出时才添加**；未提则不补（避免对公文画蛇添足）。

## 四、转交执行
判定完成后，真正落地校正请调用 **`gongwen-format`** 技能：
- 校正已有 docx → `reformat_plain`（通用，不写死文件）
- 原文已是公文 → `apply_incremental`（仅改不合规处）
- 从零生成报告/通知 → `gen_report.py` / `gen_notice.py`

## 五、易错点（沉淀自本项目）
- `line_spacing` 必须用 `Pt()`（存 twips、rule=exact）；误用 float 会被 python-docx 当倍行距（28×）致行距崩溃。
- 中文标记**不再恒为标题**——必须过长度 + 后续序号两道判定，否则会把长概括句或枚举首句误判为标题。
- 结语默认不保留，且要**移除**原文已有的，而不是追加。
